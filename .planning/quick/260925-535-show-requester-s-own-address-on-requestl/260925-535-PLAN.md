# Quick Task 260925-535: Requester address on RequestLive

## Problem

RequestLive always renders the location chip as `ရန်ကုန် ဆေးရုံကြီး`, no matter what the
requester typed into the CreateRequest address field.

Root cause is not data loss — it is a prop that is never passed:

- `src/screens/RequestLive.tsx:194` declares `township = "ရန်ကုန် ဆေးရုံကြီး"` as a default
  parameter. The string is placeholder copy lifted from the design mockup (it also appears as
  the `addressExample` hint in `src/screens/CreateRequest.tsx:64`).
- `src/App.tsx:1043` renders `<RequestLive>` with `bloodType`, `unitsNeeded`, `lat`, `lng` and
  friends, but never with `township`. The default therefore fires on every render.
- The real value is already in App state as `requestDraft.address`: written on post
  (`src/App.tsx:612` -> `current_address`) and restored on reload
  (`src/App.tsx:280` <- `activeRequest.current_address`).

Showing an invented hospital name on an emergency screen is a truthfulness bug, not only a
cosmetic one: a donor reading the requester's screen over their shoulder, or a requester
checking their own post, sees a location that was never entered.

## Tasks

### Task 1 — Pass the real address and drop the invented default

- `src/App.tsx`: add `township={requestDraft?.address}` to the `<RequestLive>` props.
- `src/screens/RequestLive.tsx`: remove the `"ရန်ကုန် ဆေးရုံကြီး"` default from the destructured
  prop so nothing invents a location.
- `src/screens/RequestLive.tsx`: render the pin + location text only when the address is a
  non-empty string. When absent, the row collapses to the blood-type badge alone rather than
  showing placeholder copy.
- Verify: `npm run build` (tsc -b then vite build) passes.
- Done: posting a request with an address shows that address on RequestLive; a request with
  no address shows no pin row.

## must_haves

- truths:
  - RequestLive's location chip reflects `blood_requests.current_address` for the open request.
  - No hardcoded Myanmar location string remains in RequestLive.
  - An empty/missing address renders no location row (no invented text).
- artifacts:
  - `src/App.tsx` passes `township` to `<RequestLive>`.
  - `src/screens/RequestLive.tsx` has no default value for `township`.
